# Code of Conduct

Be respectful and constructive. Criticise code and ideas, not people. No harassment,
discrimination or personal attacks, in issues, pull requests or discussions.

Behaviour that breaks this can lead to comments being removed and people being blocked. Report
problems through a private security advisory or to the maintainer, @bertel2020.

Sei respektvoll und konstruktiv. Kritisiere Code und Ideen, nicht Personen. Keine Belästigung,
Diskriminierung oder persönlichen Angriffe. Verstöße können zu gelöschten Beiträgen und Sperren
führen.
