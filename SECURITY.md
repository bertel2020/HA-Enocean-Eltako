# Security policy

## Supported versions

Only the latest release receives fixes.

## Reporting a vulnerability

Please do not open a public issue for a security problem. Use GitHub's private reporting:
**Security → Report a vulnerability** on
[this repository](https://github.com/bertel2020/HA-Enocean-Eltako/security/advisories/new).

Include the version, what you found and how to reproduce it. You get an answer as soon as
possible; fixes are published as a new release.

---

## Sicherheitsrichtlinie

Nur die neueste Version erhält Korrekturen. Bitte melde Sicherheitsprobleme nicht als
öffentliches Issue, sondern privat über **Security → Report a vulnerability** in diesem
Repository (Link oben). Nenne Version, Fund und Schritte zur Reproduktion.
